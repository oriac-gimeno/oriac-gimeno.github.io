# Oriac Gimeno – Data & ML Portfolio

This repository contains the source code of my professional portfolio, built with Jekyll and the Type-on-Strap theme. The site is automatically deployed via GitHub Pages and showcases my projects organized by categories.

📁 **Structure**
- `_data/repos.yml`: project data (name, URL, categories).
- `projects/`: individual project files (demos, notebooks, documentation).
- `index.md`: main landing page of the portfolio.

🌐 **View the site**: [https://oriac-gimeno.github.io](https://oriac-gimeno.github.io)
